# Python 기초 퀴즈 게임 설계

## 목표

Python 3.10 이상의 표준 라이브러리만 사용해 터미널에서 실행되는 퀴즈 게임을 만든다. 사용자는 메뉴에서 퀴즈 풀기, 퀴즈 추가, 목록 보기, 최고 점수 확인, 종료를 선택할 수 있다. 추가한 퀴즈와 최고 점수는 프로젝트 루트의 `state.json`에 유지한다.

보너스 과제는 구현하지 않는다.

## 프로젝트 구조

```text
mission-1-2-quiz-game/
├── quiz_game.py
├── state.json
├── tests/
│   └── test_quiz_game.py
├── docs/
│   └── superpowers/specs/
├── .gitignore
└── README.md
```

입문자가 전체 흐름을 쉽게 설명할 수 있도록 실행 코드는 `quiz_game.py` 한 파일에 둔다. 자동 검증 코드는 `tests/test_quiz_game.py`로 분리한다.

## 클래스와 책임

### `Quiz`

- 문제, 선택지 4개, 정답 번호를 보관한다.
- 화면에 문제와 선택지를 출력한다.
- 입력한 번호가 정답인지 판정한다.
- JSON 저장에 사용할 딕셔너리와 `Quiz` 객체를 서로 변환한다.

### `QuizGame`

- 퀴즈 목록, 최고 점수, 최고 정답 수와 당시 전체 문제 수를 관리한다.
- 메뉴 출력과 메뉴 선택 처리를 담당한다.
- 퀴즈 풀기, 추가, 목록, 점수 확인을 각각 별도 메서드로 제공한다.
- `state.json`을 저장하고 불러온다.
- 숫자 입력 검증과 안전한 종료를 처리한다.

## 기본 데이터

`Python 기초`를 주제로 직접 작성한 객관식 퀴즈 5개를 제공한다. 각 문제에는 선택지 4개와 1부터 4 사이의 정답 번호가 있다.

`state.json`이 처음부터 저장소에 포함되며 다음 구조를 사용한다.

```json
{
  "quizzes": [
    {
      "question": "문제",
      "choices": ["선택지 1", "선택지 2", "선택지 3", "선택지 4"],
      "answer": 1
    }
  ],
  "best_score": null,
  "best_correct": null,
  "best_total": null
}
```

아직 게임을 하지 않은 상태는 점수 필드를 `null`로 표현한다. 게임 결과는 정답률을 기준으로 0~100점의 정수로 계산한다. 최고 점수가 같으면 기존 기록을 유지한다.

## 동작 흐름

프로그램 시작 시 저장 데이터를 불러온 후 메뉴를 반복해서 보여준다.

1. 퀴즈 풀기: 저장된 모든 문제를 차례로 출제하고 정답 여부를 알린다. 끝나면 정답 수와 100점 환산 점수를 표시하고 최고 점수를 필요할 때 갱신한다.
2. 퀴즈 추가: 문제, 비어 있지 않은 선택지 4개, 1~4 정답 번호를 입력받고 즉시 저장한다.
3. 퀴즈 목록: 등록된 문제를 번호와 함께 출력한다.
4. 점수 확인: 아직 기록이 없으면 안내하고, 있으면 최고 점수와 정답 수를 표시한다.
5. 종료: 현재 상태를 저장하고 정상 종료한다.

퀴즈가 없는 경우 풀기와 목록 기능은 안내 메시지만 출력하고 메뉴로 돌아간다.

## 오류 처리

- 모든 입력은 앞뒤 공백을 제거한다.
- 빈 입력, 숫자가 아닌 입력, 허용 범위 밖 숫자는 이유를 안내하고 같은 입력을 다시 받는다.
- `KeyboardInterrupt`와 `EOFError`가 발생하면 가능한 상태를 저장하고 안전하게 종료한다.
- `state.json`이 없으면 기본 퀴즈를 사용하고 새 파일을 만든다.
- JSON이 손상되었거나 스키마가 유효하지 않으면 안내 후 기본 퀴즈와 빈 점수 상태로 복구한다.
- 읽기 또는 쓰기 오류는 `try/except`로 처리하며 사용자에게 실패 사실을 알린다.

## 테스트 전략

Python 표준 라이브러리 `unittest`를 사용한다.

- `Quiz`의 정답과 오답 판정
- 유효한 딕셔너리 변환과 잘못된 퀴즈 데이터 거부
- 최초 실행 시 기본 퀴즈 5개 생성
- 정상적인 `state.json` 저장과 재로딩
- 없는 파일과 손상된 JSON 복구
- 최고 점수 최초 저장, 상승 시 갱신, 하락 또는 동점 시 유지
- 빈 퀴즈 목록 처리
- 숫자 입력의 공백, 문자, 빈 값, 범위 밖 값 처리

구현은 실패하는 테스트를 먼저 작성한 뒤 필요한 최소 코드만 추가하는 순서로 진행한다.
