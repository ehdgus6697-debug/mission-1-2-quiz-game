# 콘솔 실행 검증 기록

검증일: 2026-08-20

실제 제출용 화면 캡처를 만들 때 같은 순서를 재현할 수 있도록 실행 결과를 기록했다. 저장소의 기본 `state.json`을 바꾸지 않기 위해 프로그램 파일을 임시 디렉터리에 복사해서 실행했다.

## 필수 기능 시나리오

입력 순서:

```text
3 → 목록
1 → 퀴즈 풀기
1, 3, 2, 3, 1 → 기본 문제 5개 정답
4 → 최고 점수
2 → 새 퀴즈 추가
3 → 추가 후 목록
5 → 종료
```

확인 결과:

- 최초 목록에 Python 기초 문제 5개가 표시됨
- 5문제를 모두 맞혀 `5문제 중 5문제 정답 (100점)`이 표시됨
- `새로운 최고 점수` 메시지가 표시됨
- 최고 점수 화면에 `100점 (5문제 중 5문제 정답)`이 표시됨
- `새로 추가한 Python 문제`가 6번째 문제로 표시됨
- 종료 시 현재 상태 저장 안내가 표시됨

## 재시작 후 저장 유지

프로그램을 다시 실행해 목록과 점수를 확인했다.

- 목록에 6번째 문제 `새로 추가한 Python 문제`가 유지됨
- 최고 점수 `100점 (5문제 중 5문제 정답)`이 유지됨

## 잘못된 입력

메뉴에서 `abc`, `9`, 빈 입력을 차례로 입력한 뒤 정상 선택 `3`을 입력했다.

```text
선택: ⚠️ 숫자를 입력해 주세요.
선택: ⚠️ 1부터 5 사이의 숫자를 입력해 주세요.
선택: ⚠️ 값을 입력해 주세요.
선택: 📋 등록된 퀴즈 목록 (총 6개)
```

세 입력 모두 프로그램이 종료되지 않고 같은 메뉴 선택 흐름으로 복귀했다.
